> **Quick answer.** A machine running for a few seconds proves very little. Before approving a tabletop bottle labeler, test it with the containers, label rolls, operators and production pace you actually expect. The goal is a repeatable result you can compare with a written acceptance standard — not a polished demonstration on the supplier's easiest sample.

A factory acceptance test (FAT) is the pre-shipment check against an agreed application. It does not replace installation and commissioning at your site. A useful FAT makes the tested bottle and label formats, machine settings, observed defects, changeover steps and unresolved actions visible to both sides. The structure below adapts the evidence areas described in Lancing UK's bottle-labeler FAT checklist to a small-batch tabletop purchase.

## Before the Test, Define the Job

Write down what the machine must label. Include the bottle material and shape, diameter or width range, filled or empty condition, label material and dimensions, label position, target output, operator count and available floor space. If the label must face a seam, logo or panel, define the reference point. Photos alone rarely communicate a placement requirement as clearly as a drawing with a datum and allowable variation.

| Bring or define | Why it matters |
| --- | --- |
| Actual containers from the intended production lot | Surface, stiffness, seams and dimensional variation can change feeding and wrap behavior. Include the hardest format, not only a perfect sample. |
| Production-intent label rolls | Label width, gap/black mark, liner stiffness, roll direction, core and outside diameter affect threading and sensing. |
| Acceptance limits agreed in writing | Define the permitted label position range, reject conditions, minimum sustained rate and how samples will be counted. |
| Format range and changeover expectation | Name the smallest/largest or otherwise most difficult SKUs and the changeover steps that must be demonstrated. |

Do not accept an unqualified speed figure. Ask the supplier to state the conditions behind it: container, label size, operator loading, reject handling and run duration. A catalog rate is a reference for discussion; your acceptance rate is the rate the agreed application sustains under the agreed test.

## Write the Protocol Before the Supplier Powers Up

Make a one-page protocol with the machine configuration, test date, sample IDs, label-roll details, chosen settings, pass/fail limits and sign-off roles. Decide whether you are testing one SKU or a range. Record who may adjust settings and whether a change restarts the run. This prevents a demonstration from quietly changing conditions after a poor result.

## Run the Test in Stages

| Stage | What to observe and record |
| --- | --- |
| 1 · Setup and first-off | Thread the specified roll; set guides, sensor and label position. Record the setup time, settings and any supplier assistance. Inspect the first labeled bottles. |
| 2 · Short repeatability run | Run a pre-agreed sample count at the target pace. Measure label position against your datum on a consistent sample; count skew, wrinkles, bubbles, missed labels, doubles, jams and bottle damage. |
| 3 · Sustained run | Run long enough to expose roll handling, operator rhythm, sensor stability, accumulation and stoppages. Agree duration or quantity in advance; one short burst cannot demonstrate sustained output. |
| 4 · Changeover | Move to the next agreed bottle/label format. Time the changeover and capture the steps, tools, guide positions, sensor adjustments and first-off approval. |
| 5 · Fault recovery | With supplier supervision, test agreed routine events such as an empty roll, label gap/sensor issue or bottle interruption. Record stop behavior, alarm, recovery steps and whether the machine resumes without misapplied labels. |
| 6 · Evidence pack | Save the approved samples, measurement sheet, settings, photos/video, open-action list and documents promised in the purchase specification. |

## Measure What Affects Your Product

Choose a repeatable reference point on the bottle — such as the base plane, shoulder, seam or a defined panel edge — and measure label height and rotation from it. For a wrap label, also inspect the leading edge, overlap or gap, and how consistently the label ends meet. For a front/back or paired-label setup, record the relationship between the two labels. Measure enough samples to reveal spread; agree the sample size and method with the supplier before the run.

Avoid judging only by eye or by one "best" bottle. Photograph representative passes and failures from the same angle. Keep the bottle and label lot identifiers attached to the record. If the supplier's machine display reports a rate, independently count good labeled bottles over the agreed interval and exclude stoppages only under the rule you agreed beforehand.

## Set Acceptance Limits That Fit Your Application

There is no universal placement tolerance or run duration for every tabletop labeler. A narrow cosmetic label, a wide wrap label, a textured container and a high-speed production target create different acceptance needs. Put numerical limits in the purchase specification only after deciding what the finished package can tolerate. Define how you will handle a borderline measurement, a defect cluster or a supplier adjustment during the test.

## What Should Make You Pause?

| Observation | Why it matters / next step |
| --- | --- |
| The test uses different bottles or labels than your order | The result may not represent your application. Repeat with the correct production-intent samples. |
| Only the best-looking bottles are shown | Ask to inspect the complete run or a pre-agreed random sample, including rejects and stoppages. |
| The supplier quotes a rate without conditions | Ask for the exact format, operator assumptions, measurement interval and good-output definition. |
| Every format needs undocumented adjustment | Require a written setup sheet or saved recipe and demonstrate repeatability after changeover. |
| A fault requires unexplained manual intervention | Ask for the recovery procedure and record what happens to bottles already in process. |
| Open issues are described verbally only | List each issue, owner, due date and evidence needed before dispatch or final payment. |

## FAT Pass, Conditional Pass or Fail

Use a disposition that matches the evidence. Pass means every agreed requirement was demonstrated and the evidence pack is complete. Conditional pass means a specific, bounded action remains, with an owner, due date and agreed proof before shipment or payment. Fail means a critical requirement was missed or the test conditions did not represent the purchase. Avoid vague approval language such as "looks good" when commercial milestones depend on acceptance.

## Carry the Same Standard to Your Site

Keep the approved sample and setup record. At installation, repeat a shorter site acceptance test with your utilities, operators, line spacing and real production materials. Compare the result with the FAT baseline. A good factory run cannot prove that the machine will work with a different bottle lot, label construction, operator method or upstream/downstream equipment.

## Questions to Send with Your RFQ

- Can you run my actual bottle samples and production-intent label rolls before shipment?
- Which bottle and label formats are included in the quoted configuration, and which need extra parts?
- How will we define good output, label position, target rate, sample quantity and run duration?
- Can you provide the setting sheet, video of the complete test, inspection record and open-action list?
- What changeover and fault-recovery steps will you demonstrate, and what training/documents are included?
